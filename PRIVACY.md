# Privacy Policy

This plugin connects Dify to the FlexAI inference API (`https://api.flex.ai/v1`).

## What the plugin sends

When a Dify app uses a FlexAI model, the plugin sends the request content to FlexAI so the model can answer: prompts, conversation messages, tool definitions and tool results, images you attach to a vision model, and text you embed. It authenticates with the FlexAI API key you enter in Dify.

## What the plugin stores

The plugin itself stores nothing. It keeps no logs, analytics or copies of your content. Dify stores your API key as an encrypted credential, the same way it stores credentials for every model provider.

## How FlexAI handles the data

Requests are processed by FlexAI under its privacy policy: https://flex.ai/privacy-policy

## Contact

Questions about this plugin or about data handling: support@flex.ai
